# CM 2026 LiveStreaming

Urmărește în direct sportul tău preferat.

## Despre proiect

Sporturi Live este o pagină web pentru afișarea programului CM 2026, cu evenimente, ore de start, echipe participante și surse video pentru fiecare meci.

Programul grupelor, surse video pentru fiecare eveniment la o calitate HD, într-o platformă rapidă, modernă și ușor de folosit. Urmărește meciurile programate, verifică ora de start, echipele participante și accesează rapid sursele disponibile pentru fiecare partidă.

## Cum se folosește

1. Intră pe site:
   https://bebe2007.github.io/sporturi-live/

2. Caută evenimentul dorit în listă.

3. Apasă pe cardul meciului.

4. Alege una dintre sursele video disponibile.
